# Customer Orders SQL Web Demo

This folder contains a Netlify-ready browser demonstration of the Customer Orders SQL project.

## Features

- Displays customers, products, and orders
- Shows joined order details
- Calculates item totals
- Calculates total spending by customer
- Counts orders per customer
- Identifies the most expensive product
- Includes search and filtering
- Uses responsive HTML, CSS, and JavaScript

## Deploy to Netlify

1. Download and unzip this folder.
2. Open Netlify.
3. Drag the entire `customer-orders-web-demo` folder into the Netlify deploy area.
4. Wait for the deployment to show **Published**.
5. Open the production URL.

This web demo uses JavaScript data matching the original SQL scripts so visitors can interact with the project without installing SQL Server.
